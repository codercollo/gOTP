GoTP — Project Structure
========================
OTP-as-a-Service over SMS, with a built-in fraud guard. Two endpoints
(send + verify), one AT product (SMS), no LLM and no trained model — the
fraud logic is auditable adaptive statistics. Category: Fraud & SIM-Swap
Detection.

In one line: GoTP is OTP that pays for itself — it blocks the fraudulent
sends (SMS-pumping, OTP-bombing) that other providers bill you for.

Scoped out on purpose (add only when a real need appears)
---------------------------------------------------------
  migrations/ + database   In-memory store is enough for the demo; add Postgres behind data.Store later.
  remote/                  LGF's systemd/Caddy production deploy — AT Marketplace hosts the container instead.
  pkg/                     Nothing public to export; keep otp/ and guard/ internal.
  test/                    Unit tests live beside their package; add here only for a cross-package integration test.
  vendor/                  Run `go mod vendor` just before submission if the build needs it.
  TLS in-app               AT Marketplace fronts TLS; keep the NPG TLS notes in docs for self-hosting.
